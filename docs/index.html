04 — Questions

The short answers.

Everything else — code, issues, and the full licence — lives in the repository.

Is ArcPDF free?

Yes. ArcPDF is open source under the AGPL-3.0, and every feature in the app is available without a purchase or subscription.

Where are my documents stored?

On your device. ArcPDF indexes local files and keeps metadata locally. It does not upload documents to a server, and there is no cloud sync.

Does it work offline?

Yes. Reading, organizing, and the PDF tools work without a connection. A connection is only needed to check for a new release or to load this release history.

How do I install an update?

Download the latest APK and open it. Android installs it over the existing app, so your library and settings stay in place. You may need to allow installs from your browser the first time.

Does it run on iPhone or desktop?

Not currently. ArcPDF is built for Android phones and tablets. The source is available if you want to follow or contribute to other platforms.
